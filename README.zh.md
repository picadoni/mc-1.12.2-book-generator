一个完全独立的工具，用于创建 .mcfunction 脚本，只需执行一条指令即可批量生成多本游戏内书籍。

这是一个专门的网页工具，旨在将格式化的文本行转换为可执行的 Minecraft `.mcfunction` 脚本，以便批量生成自定义的多页游戏内书籍。

> 🖥️ **完全离线与自主：** 您可以将此项目下载到本地电脑上，并在任何浏览器中直接运行，**无需连接互联网**。享受绝对的自由，完全不依赖任何第三方服务器或托管！

> ⚠️ **重要提示：** 本生成器使用的指令语法完全专为 **Minecraft 1.12.2** 设计。由于指令格式的变化（自 1.13 版本引入），它与更高版本的游戏**不兼容**。

## 📖 数据输入格式指南（提示单）

为了正确生成书籍，请在输入框中使用以下格式语法：

* **换行（段落）：** `1 行 = 1 本书`。如果您想在书页文本内部进行换行，请使用 `\n` 符号。
* **分页：** 使用垂直线符号 `|` 来分隔页面。脚本会自动在游戏中创建所需的页面。
* **通用格式：** `作者;书名;第 1 页文本 | 第 2 页文本`
