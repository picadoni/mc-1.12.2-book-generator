# Генератор многостраничных книг для Minecraft 1.12.2

Специализированный веб-инструмент для преобразования форматированного текста в исполняемые скрипты Minecraft (`.mcfunction`), позволяющий массово создавать в игре пользовательские многостраничные книги.

> ⚠️ **Важно:** Этот генератор использует синтаксис команд, разработанный исключительно для **Minecraft 1.12.2**. Он несовместим с более новыми версиями игры из-за изменений в формате команд (введенных в версии 1.13).
