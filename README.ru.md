Полностью автономный инструмент для создания .mcfunction, чтобы генерировать много книг за раз, используя всего 1 команду.

Специализированный веб-инструмент, предназначенный для преобразования отформатированных текстовых строк в исполняемые скрипты Minecraft `.mcfunction` для массового создания пользовательских многостраничных книг в игре.

> 🖥️ **Полная автономность:** Вы можете скачать этот проект к себе на компьютер и запускать его локально в любом браузере абсолютно бесплатно и **без подключения к интернету**. Полная свобода и независимость от сторонних серверов!

> ⚠️ **Важно:** Этот генератор использует синтаксис команд, разработанный исключительно для **Minecraft 1.12.2**. Он несовместим с более новыми версиями игры из-за изменений в форматировании команд (введенных в версии 1.13).

## 📖 Руководство по форматированию ввода данных

Для корректного создания книг используйте следующий синтаксис форматирования в поле ввода:

* **Разрывы строк (абзацы):** `1 строка = 1 книга`. Если вы хотите сделать разрыв строки внутри текста страницы книги, используйте символ `\n`.

* **Разделение страниц:** Разделяйте страницы с помощью символа вертикальной черты `|`. Скрипт автоматически создаст необходимые страницы в игре.

* **Общий формат:** `Автор;Заголовок;Текст страницы 1 | Текст страницы 2`
