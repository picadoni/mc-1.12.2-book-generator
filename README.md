# Minecraft 1.12.2 Multi-Page Book Generator

A fully autonomous, offline-ready web constructor designed to convert formatted text lines into executable Minecraft `.mcfunction` scripts. With this tool, you can mass-spawn custom, multi-page in-game books using just **a single command**.

---

### 📋 Features & Version History (v1.0.0 / Final Release)

*Written in just one night, this project includes a rich set of features:*

1. **Mass Book Generation:** Packs multiple books into a single `.mcfunction` file at once.
2. **Custom Backgrounds:** Ability to set your own custom image as the application background.
3. **Quick Clear (Eraser):** One-click button to completely clear the text input field.
4. **5 Visual Themes:** Choose from 5 different pre-made UI styles.
5. **Color Easel:** Input custom colors to dynamically change the UI frame color.
6. **Background Reset:** Easily remove your custom background image and revert to a clean black background.

8. **Window Transparency:** Adjust the opacity/transparency of the generator window.
9. **4 Languages Supported:** Complete UI localization for English, Russian (Русский), Chinese (中文), and Japanese (日本語).
10. **Formatting Cheat Sheet:** Quick references on how to format and write books correctly.
11. **AI Assistant Shortcuts:** Useful links to free, privacy-safe AI tools to help you mass-generate tons of lore text.

This generator uses command syntax designed **exclusively for Minecraft 1.12.2**. It is **not compatible** with newer versions of the game due to major changes in command formatting introduced in version 1.13+.

---

### 📖 Data Input Formatting Guide

To generate books correctly, use the following formatting syntax in the input field:
* **Line Breaks (Paragraphs):** `1 line = 1 book`. If you want to make a line break inside the page text, use the `\n` symbol.
* **Page Splitting:** Separate pages using the vertical bar symbol `|`. The script will automatically split the text into pages inside the game.
* **General Format:** `Author;Title;Page 1 Text | Page 2 Text`
