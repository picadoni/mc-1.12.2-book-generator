# Minecraft 1.12.2 複数ページ本ジェネレーター
わずか1つのコマンドを実行するだけで、一度に多くの本を生成できる .mcfunction スクリプト作成用完全独立ツール。

フォーマットされたテキスト行を、カスタムの複数ページ本をゲーム内で大量に生成するための実行可能な Minecraft `.mcfunction` スクリプトに変換するために設計された専用のウェブツールです。

> 🖥️ **完全なオフライン＆自律性：** このプロジェクトをパソコンにダウンロードすれば、**インターネット接続なし**で、どのブラウザでもローカルに直接実行できます。外部サーバーやホスティングに依存しない、完全な自由をお楽しみください！

> ⚠️ **重要：** このジェネレーターは、**Minecraft 1.12.2** 専用に設計されたコマンド構文を使用しています。コマンド形式の変更（バージョン 1.13 以降）のため、これより新しいバージョンのゲームとは**互換性がありません**。

## 📖 データ入力フォーマットガイド（あんチョコ）

本を正しく生成するには、入力フィールドで次のフォーマット構文を使用してください：

* **改行（段落）：** `1 行 = 1 冊の本`。本のページテキスト内で改行したい場合は、`\n` 記号を使用します。
* **ページ区切り：** 垂直バー記号 `|` を使用してページを区切ります。スクリプトがゲーム内で必要なページを自動的に作成します。
* **一般的な形式：** `作者;タイトル;1ページ目のテキスト | 2ページ目のテキスト`

## 🤖 世界観（ロア）生成に役立つ AI 工具

ゲーム内の図書館を満たすための高品質なストーリーテキストが大量に必要な場合は、これらのプライバシーが保護された無料の AI アシスタントを使用して本を執筆できます：

* **AI Collaborator: Gemini** — 大量のテキスト生成やクリエイティブな本の執筆に最適です。
* **Safe Text Generator: NoTrack AI** — 匿名のテキストジェネレーター。追跡、隠れたサブスクリプション、個人データの収集なしで、クエスト、会話、本を大量に作成するのに理想的です。
